Data Cleaning & Preparation Project

 Objective:
Clean raw dataset by:
- Handling missing values
- Removing duplicates
- Fixing data formats
 Tools Used:
- Python
- Pandas
- Anaconda

 Process:
- Loaded Excel dataset
- Combined multiple sheets
- Converted Date column to datetime
- Removed duplicates and null values

 Result:
- Zero missing values
- Zero duplicate records
- Properly formatted dataset
 Key Learning
This project helped me understand the importance of data cleaning and how raw data must be prepared before analysis.
